About the status colors

Green: Good. Yellow: Moderate. Red: Poor. Gray: no valid reading. These are live dashboard guidance bands, not an official AQI or a health/safety assessment.

  • Temperature: Good 20–26 °C; Moderate 18–28 °C outside the Good range; otherwise Poor.
  • Humidity: Good 40–60%; Moderate 30–70% outside the Good range; otherwise Poor.
  • PM1.0 / PM2.5: Good ≤15; Moderate >15–35; Poor >35 µg/m³.
  • PM4.0 / PM10: Good ≤45; Moderate >45–100; Poor >100 µg/m³.
  • VOC index: Good ≤150; Moderate >150–250; Poor >250.
  • NOx index: Good ≤20; Moderate >20–50; Poor >50.

All bands are project-selected. PM1.0 and PM4.0 use heuristic bands. Gas indices are relative, not gas concentrations. An index of zero is treated as unavailable/warming up. Colors use the latest reading, not a 24-hour exposure average.
