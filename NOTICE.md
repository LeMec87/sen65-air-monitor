## Material changes

- changed the target sensor from SEN66 to SEN65 and removed the CO₂ dependency
- replaced the original display dashboard with a custom Space Grotesk layout
- added date, time, weather, day/night and display screenshot support
- added automatic IP-based location and Open-Meteo weather retrieval
- changed project/device metadata and removed the upstream OTA manifest
- created an independent build, release and documentation structure
- renamed internal display and web components for this project
